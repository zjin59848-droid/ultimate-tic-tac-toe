# 超级井字棋 · Ultimate Tic-Tac-Toe（局域网联机版）

> 一个从单文件网页小游戏迭代而来的**局域网对战游戏**：双击 `exe` 即启动服务器，
> 电脑与手机（同一 WiFi）实时联机对战。由人与 AI 协作完成。

---

## ✨ 特性

- **超级井字棋规则**：9×9 大棋盘 = 9 个小井字棋；落子位置决定对手下一步去向；被送入已结束的棋盘可自由选择
- **局域网联机**：6 位房间码 / 分享链接 / 二维码入房；WebSocket 实时同步；**服务端权威判定**（防作弊、防不同步）
- **房间管理**：昵称、座位上下台（比赛中可换人接替，局面不变）、观战、房主 👑 踢人（二次确认）/ 转让房主
- **断线处理**：自动重连、刷新不掉座、座位保留 90 秒后释放并广播
- **氛围系统**：按落子格子数三阶段（0–5 平静 / 6–11 升温 / ≥12 白热化）——背景、边框、屏幕震动联动；白热化时乌云暴雨（纯 CSS 雨幕 + 闪电闪光）
- **天气棋子**：SVG 遮罩绘制 —— X = 切角冰条交叉（三重对称，逐顶点校验）、O = 太阳（光芒缓转），随局势变色
- **分阶段 BGM**：`assets/bgm-calm|warm|hot|win.*` 四槽位自动探测、交叉淡入淡出、音量条 0–150%
- **一键特效开关**：关闭全部动画/雨/BGM 并记住选择；另有图文新手教程、作弊测试面板（`--cheat`）

## 🚀 快速开始

```powershell
# 源码运行（Python 3.9+）
pip install -r requirements.txt
python server.py            # 默认 http://127.0.0.1:8321 ，浏览器自动打开

# 打包为单文件 exe
python -m PyInstaller --onefile --name UltimateTTT \
  --add-data "index.html;." --add-data "assets;assets" server.py
```

- 双击 `index.html`（不经服务器）= **本地双人模式**，无需任何网络设置
- 手机加入：连同一 WiFi → 扫控制台二维码 / 输入局域网地址 → 输入房间码
- 自检页：`http://<你的IP>:8321/check`

## 🏗 架构

```
浏览器 (index.html)  ── HTTP  →  server.py :8321（静态页 /check /assets）
        │                         │
        └──── WebSocket ──────────┘  server.py :8322（房间/座位/落子）
                                  规则与胜负判定全部在服务端，客户端只渲染快照
```

**技术要点**：Python `websockets` 异步服务、HTTP `ThreadingHTTPServer`、客户端 ID 绑定座位（断线重连恢复）、
素材"exe 同目录 assets 优先 + 打包内置回退"的免重打包机制、SVG data-URI 遮罩图标、WebAudio/BGM 交叉淡入。

## ✅ 测试

| 层级 | 内容 |
|---|---|
| 规则层 | **4000 局**随机对局回归 + 边界用例 |
| 服务器层 | 联机集成 13 项、房间管理 12 项（踢人/转让/座位超时/比赛中接替）、作弊指令 10 项 |
| 界面层 | **234 项断言**（jsdom 加载真实页面 + 回放真实服务器录制的消息）：阶段边界、图标对称性、音量持久化等 |
| 成品层 | 打包后 exe 自检（素材 MIME、目录穿越防护、端口占用提示、BGM 逐字节比对） |
